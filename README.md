# Simple_Federated
**Διεθνές Σύστημα Σημασιολογικού Ελέγχου Δημοσίων Συμβάσεων**

## Επισκόπηση
Το Simple_Federated αποτελεί την εξέλιξη του Simple, με στόχο την ενοποίηση δεδομένων από πολλαπλές πηγές (TED, ΚΗΜΔΗΣ, Διεθνή APIs) κάτω από την οντολογία **ePO (eProcurement Ontology)** της Ευρωπαϊκής Ένωσης.

## Κύριοι Στόχοι
- **Semantic Interoperability:** Χρήση Neosemantics (n10s) για ενοποίηση διαφορετικών εθνικών σχημάτων.
- **Automated Knowledge Graph Construction (AKGC):** Αυτοματοποιημένη άντληση και επικύρωση γνώσης.
- **Agentic RAG:** Προηγμένη τεχνητή νοημοσύνη με δυνατότητα αυτόνομης χρήσης εργαλείων και μνήμης.
- **Entity Resolution:** Ταυτοποίηση και ενοποίηση διπλοεγγραφών μεταξύ εθνικών και ευρωπαϊκών βάσεων.
